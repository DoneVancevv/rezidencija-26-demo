# Резиденција 26: интерактивна презентација на зграда (демо)

Интерактивна веб-страна за продажба на станови:
- **Зградата на цел екран**, од три агли (фасада, перспектива, бочна).
- **Клик на кат:** анимација што влегува во зградата и отвора стан на тој кат.
- **3D тур низ станот,** соба по соба, со мебел.
- **Враќање кон зградата** со обратна анимација.
- **Основи по катови, табела со станови и филтри, галерија, локација и контакт.**

Страната е чист HTML/CSS/JavaScript. Нема build, нема npm и нема сервер.

---

## 🔗 Живо демо

После вклучување на GitHub Pages (чекор 2 подолу), страната е на:

```
https://<github-корисник>.github.io/<име-на-repo>/
```

## 🚀 Како да се закачи (објави) онлајн

### Опција 1: GitHub Pages (бесплатно, најлесно ако е веќе на GitHub)

1. **Направи fork или клонирај го repo-то** на твојот GitHub профил.
   - Горе десно на страната на repo-то, кликни **Fork**, па **Create fork**.
2. **Вклучи GitHub Pages:**
   1. Во repo-то оди на **Settings**, па **Pages** (во левото мени).
   2. Кај **Source** избери **Deploy from a branch**.
   3. Кај **Branch** избери **`main`** и папка **`/ (root)`**, па кликни **Save**.
3. **Почекај 1–2 минути.** Горе на истата страна ќе се појави линкот:
   `https://<твој-корисник>.github.io/<име-на-repo>/`
4. Тоа е тоа. Секој нов `git push` на `main` автоматски ја ажурира страната.

### Опција 2: Netlify (drag & drop, без GitHub)

1. Симни го repo-то: зелено копче **Code**, па **Download ZIP**. Отпакувај го.
2. Отвори **https://app.netlify.com/drop**.
3. Повлечи ја **целата отпакувана папка** (таа што го содржи `index.html`) во прозорецот.
4. Добиваш линк за неколку секунди. Од **Site settings** можеш да го смениш името или да закачиш свој домен.

> Може и поврзување со GitHub: Netlify, **Add new site**, **Import from Git**, избери го repo-то. Build command остави го празен, publish directory стави `/`.

### Опција 3: Vercel

1. На **https://vercel.com/new** кликни **Import** до repo-то.
2. Framework Preset: **Other**. Build command: празно. Output directory: `./`.
3. Кликни **Deploy**.

### Опција 4: Обичен хостинг (cPanel / FTP)

Качи ја **содржината** на папката (`index.html` + `assets/`) во `public_html` (или во подпапка). Друго не треба.

### Свој домен (пр. `rezidencija26.mk`)

- **GitHub Pages:** во **Settings**, **Pages**, **Custom domain** внеси го доменот. Кај регистраторот на доменот додај **CNAME** запис кон `<корисник>.github.io`.
- **Netlify/Vercel:** во поставките, **Domains**, **Add domain**, па следи ги упатствата.

## 💻 Локално отворање

- **Најбрзо:** двоен клик на `index.html`. Работи и без интернет, само фонтовите и мапата бараат интернет.
- **Со локален сервер** (препорачано за тестирање):
  ```bash
  python -m http.server 8000
  ```
  па отвори `http://localhost:8000`.

## 📁 Структура

| Фајл / папка | Што е |
|---|---|
| `index.html` | целата страна |
| `assets/js/data.js` | **сè што се менува за нов проект**: име, адреса, телефони, погледи, контури на катови, станови, цени, статуси, распореди на соби, галерија |
| `assets/js/app.js` | логика: херо, катови, анимации, табела, модал |
| `assets/js/viewer3d.js` + `furniture.js` | 3D тур низ станот (three.js) |
| `assets/vendor/three.min.js` | three.js r147 (локално, без CDN) |
| `assets/css/styles.css` | стилови |
| `assets/img/*-w.webp` | широки херо слики за десктоп (2000×1125, зградата на исто место) |
| `assets/img/*-m.jpg`, `*.jpg` | вертикални херо слики за телефон |
| `assets/img/wide/` | рендери за галеријата |

## ✏️ Менување податоци

Сè е во `assets/js/data.js`:

- **`PROJECT`:** име, адреса, телефони, рок на завршување.
- **`UNITS`:** секој стан: кат, површина, цена, статус (`free` / `reserved` / `sold`), распоред.
- **`LAYOUTS`:** распоред на собите (за 3D турот).
- **`GALLERY`:** слики и описи во галеријата.

Директен линк до стан: `index.html#S5`.

### Нова зграда / нов проект

1. Стави ги рендерите во `assets/img/`.
2. Во `VIEWS` внеси го секој поглед (`size` = димензии на сликата, `box` = рамка на зградата).
3. Во `FLOORS[...].polys` внеси ја контурата на секој кат за секој поглед (координати во пиксели на вертикалната слика).
4. За десктоп, во `WIDE` внеси ја широката слика и коефициентите `a, b, c`. Контурите за широката слика се пресметуваат сами.

Името „Резиденција 26“, локацијата, цените, статусите и распоредите се **примерни**. Ентериерните слики во галеријата се илустративни. Пред вистинско објавување, замени ги со вистинските податоци на инвеститорот.
